# Codex entry point

This project has one agent-neutral source of operating instructions:
`AI_OPERATOR.md`.

Read that file completely and follow its mandatory session routing. It loads
the current status, operator decisions, shared engineering/evidence rules,
machine-parity procedure and task-specific history. If `AGENTS.local.md`
exists, read it as directed there. Do not treat this Codex compatibility file
as a separate source of truth.
